## The review

> The lid: fits no container in this house, and we keep it anyway.

One line, 64 characters. The joke is the object's own behaviour: every kitchen
has a drawer of lids that fit no container in the house, and nobody throws
them away.

## How it works

`main.ts` writes the review text exactly as-is to `/output/entry.txt`.
No input, no network, no randomness — the same text on every run.

```sh
node main.ts
cat /output/entry.txt
```
